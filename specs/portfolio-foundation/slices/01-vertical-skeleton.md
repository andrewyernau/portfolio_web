# Slice 01 — Runnable vertical skeleton

Unlock one public Nginx endpoint serving the React build and proxying a Hono API connected to PostgreSQL. The visible checkpoint includes header navigation, placeholder home/publications/contact routes, language switching, and a footer.

Verify frontend tests/build, API live/readiness probes, migration from an empty database, Nginx SPA fallback, and Compose health dependencies. Capture desktop and mobile screenshots. As the last visual check, run `screenshot-critique` with an unprimed agent on the full shots and focused header/form crops. Human review is non-blocking: offer the shots for roughly five minutes, then record an evidence-based decision and proceed if there is no response.

The visual variable is structural clarity and responsive layout. Final typography, illustration style, color identity, and motion are explicitly deferred.
